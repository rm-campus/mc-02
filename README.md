# RM 校内赛机器人项目

## 项目简介

本项目面向 RoboMaster 校内赛，主要完成麦克纳姆轮底盘与机械臂的设计、制作和调试，实现机器人遥控移动、物品夹取与搬运等功能。

电控以达妙 MC02 开发板为核心，使用 STM32 和 FreeRTOS 开发。底盘采用四个 M3508 电机搭配 C620 电调，通过 CAN 总线控制；机械臂计划使用五个 UART 总线舵机，遥控端采用 FS-i6X 遥控器与 iA6B 接收机。

以上为项目计划，具体结构与功能根据比赛规则及实际调试情况调整。

## 协作安排

- 底盘与机械臂共同确认安装尺寸、重量、电源及通信接口，避免装配时出现冲突。
- 各模块先独立调试，再进行整机联调，重点验证移动、夹取、搬运及遥控失联后的处理。
- 代码、结构文件与接线说明及时同步，修改共享接口前与相关队员沟通。
- 整机装配、测试记录和赛前检查由全体队员共同完成。
